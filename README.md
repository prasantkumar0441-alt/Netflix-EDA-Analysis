# 🎬 Netflix Movies and TV Shows - Exploratory Data Analysis

## 📌 Project Overview

This project performs Exploratory Data Analysis (EDA) on the Netflix Movies and TV Shows dataset. The goal is to clean the data, analyze trends, and generate meaningful insights using Python and visualization libraries.

---

## 🎯 Objectives

- Import and clean the dataset
- Handle missing values and duplicates
- Perform data preprocessing
- Create insightful visualizations
- Discover trends and patterns in Netflix content

---

## 🛠️ Tools & Technologies

- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn

---

## 📂 Dataset

Netflix Movies and TV Shows Dataset

Columns include:

- Type
- Title
- Director
- Cast
- Country
- Date Added
- Release Year
- Rating
- Duration
- Genre

- Monthly Content Added
- Movie Duration Distribution
- Correlation Heatmap
- Duration Boxplot
- Top Directors
- Top Actors

---

## 🔍 Key Insights

- Movies dominate Netflix's content library.
- The United States has the highest number of titles.
- TV-MA is the most common content rating.
- Most content was released after 2010.
- Netflix experienced rapid content growth between 2018 and 2020.
